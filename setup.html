Archive — Home Video Player · Setup & Usage

Last updated: September 7, 2026

Archive is an Apple TV player for files you already host yourself. You point it at an SMB share on your NAS, PC or Mac and it plays what is there. There is no media server to install, no library to import, no account, and nothing leaves your network.

What you need

  • An Apple TV running tvOS 17 or later.
  • An SMB share on the same network — a NAS, a Windows share, or macOS File Sharing. SMB2 or SMB3; SMB1 is not supported.
  • The username and password for that share.

Nothing to install on the server

Archive talks SMB directly to the machine holding the files. There is no Docker image, no compose file and no companion service, because there is no server component to run. If you can already reach the share from a file manager on your laptop, Archive can read it.

Try it before connecting anything

Open the Network tab and choose Demo library. It plays bundled sample clips so you can see how the player behaves with nothing set up.

Add your share

  1. Open the Network tab. Servers found automatically appear under On your network.
  2. If yours is not listed, choose Add a server.
  3. Under Server, enter the host or IP, for example 192.168.1.20.
  4. Under Account, enter the username and password for the share.
  5. Choose Connect. Archive asks the server which shares it offers and lists them.
  6. Pick the share you want and confirm its name.

You do this once. The share is saved on the Apple TV, and the password is stored in the device Keychain only — it is never written to disk in the clear and never synced anywhere.

Where your files show up

  • Timeline — everything grouped by month, newest first, with a rail that jumps to any month.
  • Folders — the folder structure of your drive, exactly as it is on disk.
  • Favorites and History — what you marked, and what you watched. Longer videos resume where you left off.

Photos play as a slideshow with a dwell time you choose in Settings, and Archive can play calm background music under media that has no audio of its own.

Use your phone as the remote

The Apple TV serves its own web page, so any browser on the same network becomes a remote and you never type on the TV.

  1. In the Network tab, select the Web server online button.
  2. Scan the QR code shown, or type the address it displays — it is http://<your-apple-tv-ip>:8570/app.
  3. Browse, search, and start playback from the phone. The video plays on the TV.

To lock the page, go to Settings → Network → Set PIN. The PIN itself never travels over the network; the browser sends only a hash of it, and the page remembers it so you enter it once per device.

If a share will not connect

Each saved share shows its own status. What each one means:

  • Online — reachable and signed in. Nothing to do.
  • Sign-in failed — the server answered but rejected the account. Check the username and password, and whether the account is allowed on that specific share.
  • Unreachable — nothing answered at that address. Check the host or IP, that the machine is awake, that file sharing is switched on, and that TCP port 445 is not blocked by a firewall.

To measure a share, press and hold the select button on its row and choose Test speed. It reads the largest video it knows about and reports average, minimum and current throughput in MB/s. The same menu removes a share.

A note on very large files

Archive is built for high-bitrate footage — drone flights and camera originals at 100 Mbit/s and above — and it plays those by downloading to the Apple TV while you watch, then handing the running player onto the local copy without a restart.

It cannot raise the Apple TV's hardware decoder ceiling. A file encoded beyond what the device can decode will not play smoothly on any app, and Archive tells you that plainly rather than showing you a black screen.
