SMB on Apple TV

Play files from a network share on Apple TV.

If your videos already live on a NAS, Mac or Windows PC, you can open the share directly on your TV. Archive uses SMB, the file-sharing protocol those devices commonly provide.

What you need

  • An Apple TV running tvOS 17 or later.
  • An SMB2 or SMB3 share reachable on the same local network.
  • A username and password allowed to read that share.

Archive reads files from the share you choose. You do not need to install a separate media server or upload your library. If you have not set up SMB on the computer or NAS yet, enable file sharing there first.

Connect in Archive

  1. Open Archive's Network tab and look under On your network.
  2. Select a detected server, or choose Add a server and enter its local address.
  3. Enter the share account, choose Connect, and select the share containing your media.
  4. Open Folders to follow the directory structure, or Timeline to browse by date.

You can try the bundled demo library first if you want to see the player before connecting a share. For screen-by-screen instructions, see the setup guide.

If the server does not appear

Discovery is convenient but not required: enter the server's local IP address manually. If it still cannot connect, confirm that the server is awake, SMB file sharing is enabled, the TV is on the same network, and the firewall allows SMB traffic. A sign-in error means the server answered but rejected the account or share permission.

For large video files

Archive downloads ahead during playback to reduce stalls caused by a short network buffer. The Apple TV still has to support the file's codec and bitrate. Read the 4K footage guide if a file remains difficult to play.
